# 管理側の準備（Googleフォーム → スプレッドシート → 公開CSV）

## 1. Googleフォームを作る

タイトル例：「HACK THE LPIC 2 合格報告」

| 質問 | 形式 | 必須 | 選択肢・補足 |
|---|---|---|---|
| 社員番号 | 記述（短文） | ○ | 重複報告の除外と、201/202 の突き合わせに使う |
| 試験 | ラジオボタン | ○ | `201` / `202` |
| 結果 | ラジオボタン | ○ | `合格` / `不合格` |
| スコア | 記述（短文・数値） | − | 200〜800（画面には出さない） |

- 質問の **順番と文言をこの表どおり** にすると、回答シートの列がページ側の想定（`data/sample.csv`）と一致します。
- 「回答」タブ →「スプレッドシートにリンク」で回答シートを作成。

## 2. 回答シートを CSV で公開する

1. 回答シートを開く →「ファイル」→「共有」→「ウェブに公開」
2. 対象：回答が入っているシート（例：`フォームの回答 1`）、形式：**カンマ区切り形式（.csv）**
3. 「公開」→ 表示された URL をコピー
4. その URL を `config.js` の `csvUrl` に貼る

注意：
- 公開 CSV は **URL を知っている人なら誰でも見られます**。社員番号を出したくない場合は、別シートに `=QUERY('フォームの回答 1'!A:G,"select A,B,C,D,E,G")` などで必要な列だけ抜き出し、そのシートを公開してください（社員番号は突き合わせに必要なので、ハッシュ化する場合はページ側と相談）。
- Google 側のキャッシュで、反映まで最大 5 分程度かかることがあります。

## 3. 受講者への案内文（例）

> 合格したら、こちらのフォームから報告してください 👉 （フォームURL）
> 不合格だった場合も報告してください（合格率の計算に使います）。名前はカウンターに一切表示されません。

## サンプルデータ（data/sample.csv）での期待値

受講者の総数（母数）は使いません。合格率 ＝ 合格者 ÷ 受験者（その試験で報告した人）。

| 項目 | 期待値 | 理由 |
|---|---|---|
| 201 合格者 | **5** | E1001, E1002, E1003, E1005, E1006（E1005 は重複報告） |
| 201 受験者 | 6 | 上記＋E1004（不合格） |
| 201 合格率 | **83%** | 5 ÷ 6 |
| 202 合格者 | **2** | E1001, E1003 |
| 202 受験者 | 3 | 上記＋E1007（不合格） |
| 202 合格率 | **67%** | 2 ÷ 3 |
| LPIC-2 認定 | **2** | 201・202 両方合格：E1001, E1003（HALL OF FAME は No.01, No.02） |
| PHASE 201 で見たとき | 201：5人・83%、202・認定はロック表示 | 202 のデータがあっても PHASE 201 では出さない |
| HALL OF FAME（PHASE 202） | CERTIFIED No.01, No.02 ＋ 空き枠 | 名前は出さない |
| クレジット（新しい順） | EXAM 202 2人目、202 1人目、201 5人目、201 4人目、201 3人目、201 2人目、201 1人目 | PHASE 201 では 201 の5件だけ |
