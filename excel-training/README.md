# Excel実務トレーニング

作業依頼を読み解き、手順を組み立て、**手元のExcelで**解く研修アプリです。結果を貼り付けるとその場で判定し、間違えたときは「どこでつまずいたか」を返します。

- 12ミッション（4段階）× 7ステップ：依頼を読む → ゴールを決める → 手順を組む → Excelで作業 → 検算する → 提出 → 報告する
- 考え方の型／データ地図／道具箱／講師画面（正解・指導メモ・教材改善点）
- 受講データ：一覧データ.xlsx・請求データ.xlsx・マスタデータ.xlsx（研修用ZIP。別途配布）
- 基準日：2025年7月1日（依頼文の「本日」「現在」はこの日として扱う）

`index.html` 1ファイルで動きます。サーバーや費用は不要です。

---

## 1. GitHub Pagesで公開する（無料）

1. GitHubで新しいリポジトリを作る（**Public**。無料プランのPagesは公開リポジトリのみ対応）
2. 「Add file → Upload files」で `index.html` と `README.md`（必要なら `apps-script` フォルダも）をアップロードし、Commit
3. リポジトリの **Settings → Pages** を開く
4. 「Build and deployment」の Source を **Deploy from a branch**、Branch を **main / (root)** にして Save
5. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます（Settings → Pages の上部にURLが表示されます）

> URLを知っていれば誰でも開けます。また、ページのソースから正解データと講師パスコードを読むことができます。

## 2. 進捗を講師が集める（任意・無料）

設定しない場合、進捗は受講者それぞれのブラウザに保存されます。受講者にホーム画面の「進捗をテキストでコピー」で送ってもらってください。

自動で集めたい場合は、Googleスプレッドシートを受け皿にします。

1. Googleスプレッドシートを新規作成（名前は自由。例：Excel研修_進捗）
2. メニュー **拡張機能 → Apps Script** を開き、最初からあるコードを消して `apps-script/Code.gs` の中身を貼り付け、保存
3. 右上 **デプロイ → 新しいデプロイ** → 種類の歯車から **ウェブアプリ** を選ぶ
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 「デプロイ」→ 初回はGoogleの承認画面が出るので許可 → 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）をコピー
5. `index.html` の冒頭付近にある設定を書き換えて、GitHubに再アップロード

```js
window.XL_CONFIG={
  sheetUrl:'https://script.google.com/macros/s/xxxxxxxx/exec'
};
```

受講者がホーム画面で名前を入力すると、スプレッドシートの「進捗」シートに **受講者×ミッションごとに1行** が記録され、進むたびに更新されます（状態・ステップ・判定回数・ヒント数・つまずきの内容・所要時間・手順メモ・報告文）。

> 「全員」にアクセスを許可したURLは、知っている人なら誰でもシートに書き込めます。URLは研修参加者以外に広めないでください。Code.gsはミッション番号の形式や文字数をチェックし、数式として実行される文字を無効化しています。

## 3. 講師画面

- メニューには表示されません。`https://<ユーザー名>.github.io/<リポジトリ名>/#teacher` を開き、講師パスコードを入力します（パスコードはこのREADMEやソースには書かれていません。別途共有されたものを使ってください）。
- 一度開いた端末ではパスコードを記憶し、メニューに「講師」が出ます。共用PCでは、講師画面の「この端末で講師画面を閉じる」で解除してください。
- ミッションごとの正解・狙い・よくあるつまずき・問いかけ例と、現行教材の改善点を表示します。

## 4. 正解の扱い

- ページ内に正解そのものは入っていません。受講者の入力を一方向のハッシュに変換して照合するため、ソースを見ても正解は分かりません。
- 解説・模範例は暗号化されていて、**正解した受講者の画面でだけ**開きます（正解の値が鍵になります）。講師用データは講師パスコードで暗号化されています。
- 限界：ハッシュは「総当たり」で破れるため、プログラムを書ける人が時間をかければ数値の正解を割り出せます。受講者がソースを覗いて答えを見る、といった通常の範囲は防げます。
- 「ギブアップして答えを見る」機能はありません。3回以上間違えると、ヒントの見直しと講師への相談を促します。

## 5. 内容を直したいとき

文面・正解・パスコードを変えるには、ハッシュと暗号文を作り直す「ビルド」が必要です。直接 `index.html` を書き換えると判定が壊れることがあるので、作成者に依頼してください（`sheetUrl` の書き換えだけは自由にできます）。

## 補足

- claude.ai上で公開した版にあった「AIコーチ」と「進捗のクラウド自動保存」は、GitHub Pagesでは表示されません（それ以外の機能はすべて同じです）。
- 暗号処理にブラウザの標準機能（Web Crypto）を使うため、https（GitHub Pages）で開いてください。
- 動作確認ブラウザ：Chrome / Edge の最新版
